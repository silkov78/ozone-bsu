# Статус работ

## Сделано

**Фронт**
- Новые шаблоны по макету: главная, наблюдения, новости (список/страница), о центре,
  сотрудник, прибор, статья, документы, поиск, политика конфиденциальности.
- Единые стили `static/css/site.css`, помощники `static/js/site.js`, графики — Chart.js 4.4.1 (CDN).
- Старый фронт (Bootstrap-тема, `static/vendor`, `static/js`, старые шаблоны) удалён.
- Все тексты интерфейса обёрнуты в `{% trans %}`; переключатель RU/BE/EN через `set_language`.

**Наблюдения**
- Главная: три станции, переключение параметра и периода, мини-графики с осями и анимацией прорисовки.
  Для Гомеля/Нарочи показывается своя дата последних данных (приходят с задержкой).
- Страница наблюдений: график по выбранному городу, карточка последних данных, выгрузка.
- Выгрузка `/observations/export/?from=&to=&format=csv|xlsx` — все пункты и параметры за период.

**Бэкенд / БД**
- `News.source_url` — «Оригинальный источник». Миграция `main_app/0013` заполнила его
  у 4 новостей (id 23, 34, 35, 36), где ссылка стоит в самом конце текста.
- `subtitle` (новости и статьи) стал необязательным; `subtitle` и `tag` у новостей остались в БД,
  но скрыты в админке и не выводятся на сайте.
- CKEditor 5 в админке для текстов новостей и статей (все языки), загрузка картинок в `media/main/editor/`.
- Тексты отображаются фильтром `rich_text`: HTML из редактора — как есть, старый простой текст — абзацы + кликабельные ссылки.
- 301-редиректы со старых адресов (`/blog/`, `/observations/info/`, `/observations/download/`, `/staff/`, `/articles/`, `/devices/`).
- Тесты представлений переписаны под новый фронт (`tests/test_views.py`), исправлены устаревшие тесты моделей. `manage.py test` — 24 теста, OK.

**Инфраструктура (dev)**
- `local_data/` (в `.gitignore`): дамп БД, архив и распакованные медиа, xlsx с наблюдениями.
- `docker/initdb/00-restore.sh` — автозаливка дампа в новый том Postgres.
- `compose.dev.yml`: медиа монтируются из `local_data/media`, порты 5433/8000/8081.
- `Dockerfile.dev`: убран `makemigrations` при старте (миграции коммитятся), `admin/ozone` для dev.
- `.env.dev`: `ALLOWED_HOSTS` без кавычек + `localhost`.
